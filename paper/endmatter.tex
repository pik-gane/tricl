\section*{Use of AI tools}
\emph{Tools.} This work used Anthropic's Claude Code (cloud sessions, September--November 2026) with the models [MODELS], including parallel sub-agents of the same models.

\emph{Substantive use.} Under the author's direction, the AI system wrote most of the current version of \tricl\ (including leg influences, actions with decaying impacts, forced events, triggered acts, the replay mode with analytic gradients, time-rescaling residuals, and their tests) and the scripts of this study (data processing, model specifications, fitting, the competing aging model, residuals, closures, figures and tables).
It ran the fits and simulations reported here, searched and checked the literature, and drafted the text of this paper.

\emph{Assistive use.} Copy-editing, consistency checks between text, code and generated numbers, and checking of bibliographic data against Crossref.

\emph{Direction and verification.} The author designed the model class and wrote the original simulator, set the requirements for the study (an application with Markovian dynamics, a comparison with a competing model, a higher-order closure), approved the written research plan, and reviewed the changes and the text.
The code is verified by an automated test suite run in continuous integration: exact log-likelihoods against closed forms and independent computations (including a Hawkes process), exact stationary distributions of small models against long simulations, analytic gradients against finite differences, replayed against simulated log-likelihoods, time-rescaling residuals of simulated data against the unit exponential distribution, and, in debug mode, the recomputation of every rate after every event; the separate implementation of the competing model agrees with \tricl\ to $10^{-12}$ where the models coincide.
Every number, table and figure in the paper is produced by scripts from the code and the public data, so that it can be regenerated and checked.
The author takes full responsibility for the content of the paper.
